# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when
working with code in this repository.

**Always read [AGENTS.md](AGENTS.md) first, at the start of every
session, before doing anything else.** It is the entry point for
all agent work in this repo: project overview, hard constraints,
how to run and verify the project, and links into `harness/docs/`
for details.

If `AGENTS.md` still starts with a `<!-- SETUP: ... -->` comment or
contains `{{PLACEHOLDER}}` values, run the `harness-setup` skill
before anything else.

There are no Claude-Code-specific instructions beyond that: follow
`AGENTS.md` and the files it links to.
